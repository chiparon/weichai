# 检索模块对比测试方案

## 一、测试目标

对比本项目 **SeekDB 检索器** 与 **主流 LLM Agent**（如 Claude Code、CodeX、Trae 等）在相同代码检索需求下的表现差异。

- **被测系统 A**：ForeXplore SeekDB 检索服务（hybrid 模式：语义向量 + 全文检索）
- **对照系统 B**：LLM Agent 直接基于代码语料库进行检索（通过提示词 + 工具调用）

---

## 二、测试范围

### 2.1 测试任务（5 个 Benchmark 任务）

| # | taskId | 目标方法 | 核心需求摘要 |
|---|--------|---------|------------|
| 1 | `quote-cache-001` | `RateQuoteService.getQuote` | 5 秒 TTL 缓存 + 单飞加载 + 过期兜底 + 同币种合并 |
| 2 | `batch-settlement-002` | `SettlementService.settleBatch` | 批量幂等结算 + 只重试失败项 + 防重复回执 + 保持顺序 |
| 3 | `provider-routing-003` | `ProviderRouter.fetchQuote` | 主备路由 + 隔离熔断器 + 半开恢复 + 语义保留回退 |
| 4 | `trade-consumer-004` | `TradeEventConsumer.consume` | 按消息 ID 精确一次 + 按账户串行 + 跨账户并行 |
| 5 | `audit-buffer-005` | `AuditLogBuffer.flush` | 阈值/定时批量写出 + 关闭时排空 + 写入失败保留数据 |

### 2.2 检索语料库

- **路径**：`fixtures/code-corpus/`
- **规模**：12 个仓库、794 个符号、~62K 行代码
- **语言**：TypeScript(3) / Python(3) / Java(2) / Go(2) / Rust(2)

### 2.3 评分标准 Ground Truth

- **来源**：`fixtures/benchmark/relevance.jsonl`（90 条人工标注）
- **每任务 18 条**：high(2) + medium(4) + low(2) + distractor(10)

| 相关性等级 | 数值 | 含义 |
|-----------|------|------|
| high (3) | 3 | 高度可复用，行为匹配度高 |
| medium (2) | 2 | 部分可复用，需适配/包装 |
| low (1) | 1 | 少量可复用片段，基本不兼容 |
| distractor (0) | 0 | 仅词法相似，行为无关（干扰项） |

## 三、对比维度设计

### 3.1 人工初步对比维度

对每个任务的 Top-3 结果，逐项对比：

| 对比维度 | 说明 | 评判方式 |
|---------|------|---------|
| **A. 高相关命中率** | Top-3 中是否包含 high 级别候选 | 命中 ≥1 个 high = ✓ |
| **B. 干扰项排除** | Top-3 中是否混入 distractor | 出现 distractor = ✗ |
| **C. 排序合理性** | high > medium > low 的排序是否正确 | 人工判断排序逻辑 |
| **D. 覆盖度** | Top-3 是否来自不同仓库/语言 | 多样性评估 |
| **E. 语义理解** | 是否理解了需求的核心行为语义而非词法匹配 | 人工分析候选与需求的行为对应关系 |
| **F. 跨语言能力** | 是否正确检索到跨语言的高相关候选 | 检查不同语言候选的命中 |
| **G. 结果可解释性** | 返回的 score/preview/summary 是否有助于判断相关性 | 人工评估信息充分性 |

### 3.2 批量自动化对比指标

| 指标 | 计算方式 | 含义 |
|------|---------|------|
| **Precision@3** | Top-3 中 high/medium 占比 | 前 3 结果的精确率 |
| **Precision@5** | Top-5 中 high/medium 占比 | 前 5 结果的精确率 |
| **Recall@10** | Top-10 中命中 high+medium 数 / 总数(6) | 前 10 结果的召回率 |
| **MRR** | Mean Reciprocal Rank | 首个 high 候选的倒数排名均值 |
| **NDCG@3** | 折损累积增益（high=3, medium=2, low=1, distractor=0） | 考虑排序质量的指标 |
| **NDCG@5** | 同上，Top-5 | 更宽松的排序质量 |
| **Distractor@3** | Top-3 中 distractor 数量 | 干扰项渗透率 |
| **High-Hit@3** | Top-3 至少命中 1 个 high 的任务数 / 5 | 高相关命中率 |

### 5.1 SeekDB 检索自动化脚本

编写脚本 `scripts/eval_seekdb_retrieval.ts`，直接调用检索 API 获取 5 个任务的结果，与 ground truth 对比计算指标。

```

// scripts/eval_seekdb_retrieval.ts
import * as fs from 'fs';
import * as path from 'path';

interface RelevanceRecord {
  taskId: string;
  candidateRepository: string;
  candidateSymbol: string;
  relevance: 'high' | 'medium' | 'low' | 'distractor';
}

interface SearchCandidate {
  id: string;
  title: string;
  repository: string;
  language: string;
  score: { overall: number };
}

interface TaskRecord {
  taskId: string;
  targetSymbol: string;
  targetPath: string;
  requirement: string;
  constraints: string[];
}

const RELEVANCE_WEIGHT: Record<string, number> = {
  high: 3, medium: 2, low: 1, distractor: 0,
};

function loadRelevance(filepath: string): RelevanceRecord[] {
  const raw = fs.readFileSync(filepath, 'utf-8').trim();
  return raw.split('\n').map(line => JSON.parse(line));
}

function loadTasks(filepath: string): TaskRecord[] {
  const raw = fs.readFileSync(filepath, 'utf-8').trim();
  return raw.split('\n').map(line => JSON.parse(line));
}

function buildGroundTruthMap(relevance: RelevanceRecord[]): Map<string, Map<string, number>> {
  const map = new Map<string, Map<string, number>>();
  for (const r of relevance) {
    if (!map.has(r.taskId)) map.set(r.taskId, new Map());
    const key = `${r.candidateRepository}::${r.candidateSymbol}`;
    map.get(r.taskId)!.set(key, RELEVANCE_WEIGHT[r.relevance]);
  }
  return map;
}

function computeMetrics(
  taskId: string,
  candidates: SearchCandidate[],
  gt: Map<string, Map<string, number>>
) {
  const taskGT = gt.get(taskId)!;
  const top3 = candidates.slice(0, 3);
  const top5 = candidates.slice(0, 5);
  const top10 = candidates.slice(0, 10);

  // precision@k (count high+medium in top-k / k)
  const precision = (top: SearchCandidate[]) => {
    const rel = top.filter(c => {
      const key = `${c.repository}::${c.title}`;
      return (taskGT.get(key) ?? 0) >= 2; // medium or high
    }).length;
    return rel / top.length;
  };

  // recall@k
  const totalRelevant = [...taskGT.values()].filter(v => v >= 2).length;
  const recall = (top: SearchCandidate[]) => {
    const found = top.filter(c => {
      const key = `${c.repository}::${c.title}`;
      return (taskGT.get(key) ?? 0) >= 2;
    }).length;
    return found / totalRelevant;
  };

  // NDCG@k
  const dcg = (top: SearchCandidate[]) => {
    return top.reduce((sum, c, i) => {
      const key = `${c.repository}::${c.title}`;
      const rel = taskGT.get(key) ?? 0;
      return sum + (Math.pow(2, rel) - 1) / Math.log2(i + 2);
    }, 0);
  };
  const idcg = (k: number) => {
    const sorted = [...taskGT.values()].sort((a, b) => b - a).slice(0, k);
    return sorted.reduce((sum, rel, i) => {
      return sum + (Math.pow(2, rel) - 1) / Math.log2(i + 2);
    }, 0);
  };
  const ndcg = (top: SearchCandidate[]) => {
    const id = idcg(top.length);
    return id === 0 ? 0 : dcg(top) / id;
  };

  // MRR
  const mrr = (() => {
    for (let i = 0; i < candidates.length; i++) {
      const key = `${candidates[i].repository}::${candidates[i].title}`;
      if ((taskGT.get(key) ?? 0) === 3) return 1 / (i + 1); // high
    }
    return 0;
  })();

  // distractor count in top-3
  const distractorCount = top3.filter(c => {
    const key = `${c.repository}::${c.title}`;
    return (taskGT.get(key) ?? -1) === 0;
  }).length;

  return {
    precision3: precision(top3),
    precision5: precision(top5),
    recall10: recall(top10),
    ndcg3: ndcg(top3),
    ndcg5: ndcg(top5),
    mrr,
    distractorAt3: distractorCount,
    highHit3: top3.some(c => {
      const key = `${c.repository}::${c.title}`;
      return (taskGT.get(key) ?? 0) === 3;
    }),
  };
}

async function searchSeekDB(task: TaskRecord): Promise<SearchCandidate[]> {
  const body = {
    target: {
      id: task.taskId,
      name: task.targetSymbol.split('.').pop()!,
      kind: 'function',
      path: task.targetPath,
      language: 'TypeScript',
      signature: `${task.targetSymbol.split('.').pop()!}(...): Promise<any>`,
    },
    requirement: task.requirement,
    topK: 10,
    retrievalMode: 'hybrid',
    repositoryScopes: [],
  };

  const resp = await fetch('http://127.0.0.1:8787/v1/search', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(body),
  });

  if (!resp.ok) throw new Error(`Search failed: ${resp.status}`);
  const data = await resp.json();
  return data.candidates;
}

async function main() {
  const tasks = loadTasks('fixtures/benchmark/tasks.jsonl');
  const relevance = loadRelevance('fixtures/benchmark/relevance.jsonl');
  const gt = buildGroundTruthMap(relevance);

  console.log('='.repeat(80));
  console.log('SeekDB Retrieval Evaluation');
  console.log('='.repeat(80));

  const allMetrics: any[] = [];

  for (const task of tasks) {
    console.log(`\n--- ${task.taskId} ---`);
    const candidates = await searchSeekDB(task);
    const metrics = computeMetrics(task.taskId, candidates, gt);

    console.log(`  Precision@3:  ${(metrics.precision3 * 100).toFixed(1)}%`);
    console.log(`  Precision@5:  ${(metrics.precision5 * 100).toFixed(1)}%`);
    console.log(`  Recall@10:    ${(metrics.recall10 * 100).toFixed(1)}%`);
    console.log(`  NDCG@3:       ${metrics.ndcg3.toFixed(3)}`);
    console.log(`  NDCG@5:       ${metrics.ndcg5.toFixed(3)}`);
    console.log(`  MRR:          ${metrics.mrr.toFixed(3)}`);
    console.log(`  Distractor@3: ${metrics.distractorAt3}`);
    console.log(`  High-Hit@3:   ${metrics.highHit3}`);

    // print top-3 for manual verification
    console.log('  Top-3:');
    candidates.slice(0, 3).forEach((c, i) => {
      const key = `${c.repository}::${c.title}`;
      const rel = gt.get(task.taskId)?.get(key) ?? -1;
      const relName = ['distractor', 'low', 'medium', 'high'][rel] ?? 'unknown';
      console.log(`    ${i + 1}. [${relName}] ${c.repository}/${c.title} (${c.language}) score=${c.score.overall.toFixed(3)}`);
    });

    allMetrics.push({ taskId: task.taskId, ...metrics });
  }

  // aggregate
  console.log('\n' + '='.repeat(80));
  console.log('AGGREGATE METRICS (macro-average across 5 tasks)');
  console.log('='.repeat(80));

  const avg = (key: string) => allMetrics.reduce((s, m) => s + m[key], 0) / allMetrics.length;
  console.log(`  Avg Precision@3:  ${(avg('precision3') * 100).toFixed(1)}%`);
  console.log(`  Avg Precision@5:  ${(avg('precision5') * 100).toFixed(1)}%`);
  console.log(`  Avg Recall@10:    ${(avg('recall10') * 100).toFixed(1)}%`);
  console.log(`  Avg NDCG@3:       ${avg('ndcg3').toFixed(3)}`);
  console.log(`  Avg NDCG@5:       ${avg('ndcg5').toFixed(3)}`);
  console.log(`  Avg MRR:          ${avg('mrr').toFixed(3)}`);
  console.log(`  Avg Distractor@3: ${avg('distractorAt3').toFixed(1)}`);
  console.log(`  High-Hit@3 Rate:  ${allMetrics.filter(m => m.highHit3).length}/${allMetrics.length}`);

  // save results
  fs.writeFileSync('results/seekdb_eval.json', JSON.stringify(allMetrics, null, 2));
  console.log('\nResults saved to results/seekdb_eval.json');
}

main().catch(console.error);
```

function parseAgentResponse(text: string): any[] {
  // extract JSON array from response
  const match = text.match(/```json\s*([\s\S]*?)\s*```/) || text.match(/\[[\s\S]*\]/);
  if (!match) throw new Error('Could not parse JSON from agent response');
  return JSON.parse(match[1] || match[0]);
}

async function queryAgent(prompt: string): Promise<string> {
  // 使用 Anthropic Messages API
  const resp = await fetch('https://api.anthropic.com/v1/messages', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'x-api-key': process.env.ANTHROPIC_API_KEY!,
      'anthropic-version': '2023-06-01',
    },
    body: JSON.stringify({
      model: 'claude-sonnet-4-20250514',
      max_tokens: 4096,
      messages: [{ role: 'user', content: prompt }],
    }),
  });

  if (!resp.ok) throw new Error(`API error: ${resp.status} ${await resp.text()}`);
  const data = await resp.json();
  return data.content[0].text;
}

// ---- 辅助函数 ----
function loadTasks(fp: string) {
  return fs.readFileSync(fp, 'utf-8').trim().split('\n').map(l => JSON.parse(l));
}
function loadRelevance(fp: string) {
  return fs.readFileSync(fp, 'utf-8').trim().split('\n').map(l => JSON.parse(l));
}
function buildGroundTruthMap(rel: any[]) {
  const m = new Map<string, Map<string, number>>();
  for (const r of rel) {
    if (!m.has(r.taskId)) m.set(r.taskId, new Map());
    const w = { high: 3, medium: 2, low: 1, distractor: 0 }[r.relevance] ?? 0;
    m.get(r.taskId)!.set(`${r.candidateRepository}::${r.candidateSymbol}`, w);
  }
  return m;
}
function computeMetrics(taskId: string, candidates: any[], gt: Map<string, Map<string, number>>) {
  const taskGT = gt.get(taskId)!;
  const top3 = candidates.slice(0, 3);
  const totalRel = [...taskGT.values()].filter(v => v >= 2).length;

  const precision3 = top3.filter(c => {
    const key = `${c.repository}::${c.title}`;
    return (taskGT.get(key) ?? 0) >= 2;
  }).length / 3;

  const recall10 = candidates.slice(0,10).filter(c => {
    const key = `${c.repository}::${c.title}`;
    return (taskGT.get(key) ?? 0) >= 2;
  }).length / totalRel;

  let mrr = 0;
  for (let i = 0; i < candidates.length; i++) {
    const key = `${candidates[i].repository}::${candidates[i].title}`;
    if ((taskGT.get(key) ?? 0) === 3) { mrr = 1 / (i + 1); break; }
  }

  const dc = top3.filter(c => {
    const key = `${c.repository}::${c.title}`;
    return (taskGT.get(key) ?? -1) === 0;
  }).length;

  return {
    precision3,
    recall10,
    mrr,
    distractorAt3: dc,
    highHit3: top3.some(c => {
      const key = `${c.repository}::${c.title}`;
      return (taskGT.get(key) ?? 0) === 3;
    }),
  };
}

### 5.3 如果 Agent 无法直接访问本地文件（备选方案）

如果 Agent API 不支持文件系统工具调用，采用**语料库摘要注入**方式：

1. 用脚本将每个仓库的核心信息提取为摘要：

```bash
# 对每个仓库，提取 manifest + 所有非测试源文件的路径和摘要
for repo in fixtures/code-corpus/*/; do
  name=$(basename "$repo")
  echo "## $name"
  cat "$repo/manifest.json" | jq -r '.repository, .language'
  find "$repo" -name '*.ts' -o -name '*.py' -o -name '*.java' -o -name '*.go' -o -name '*.rs' \
    | grep -v '_test\|test_\|spec\|__test' \
    | while read f; do
      echo "  $f"
    done
  echo ""
done > results/corpus_summary.txt
```

2. 将 `corpus_summary.txt` 作为提示词的 System Prompt 上下文，让 Agent 基于文件路径和命名进行推断。

> **局限**：这种方式的 Agent 只能靠路径/命名语义推断，无法真正阅读代码行为，测试价值有限。建议优先使用支持工具调用的 Agent（Claude Code、Cursor 等可直接操作本地文件的工具）。

## 九、注意事项

1. **嵌入模型一致性**：SeekDB 当前使用 `BAAI/bge-m3`（1024 维），更换嵌入模型会影响结果
2. **检索模式**：本测试使用 `hybrid` 模式（语义 0.5 + 文本 0.2 + 符号 0.15 + 契约 0.15），单独测 `semantic` 或 `structure` 结果可能不同
3. **Ground Truth 的局限性**：当前 ground truth 只有 90 条标注（每任务 18 条），未覆盖语料库全部 794 个符号。如果检索返回未标注的符号，需要人工额外判断
4. **Agent 的不确定性**：LLM 输出有一定随机性（temperature），建议每任务执行 3 次取平均
5. **Agent 的提示词工程**：提示词质量直接影响 Agent 表现。实际测试时可能需要迭代优化提示词，并在报告中记录最终使用的提示词版本
